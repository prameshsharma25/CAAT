### How to Get Involved

If you are using CAAT in your research and wish to contribute to its development:

* **Report Bugs:** Please open an [Issue](https://github.com/prameshsharma25/CAAT/issues) on GitHub with a description of the error and a minimal reproducible example.
* **Feature Requests:** We are actively looking to expand the visualization capabilities. Suggestions are always welcome.
* **Pull Requests:** Feel free to fork the repository and submit a PR for any bug fixes or performance improvements.
